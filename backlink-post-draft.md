# I built a mini calculator with plain HTML, CSS & JS — no frameworks

Just finished a small side project: a simple, fast calculator that runs
entirely in the browser. No React, no build tools — just vanilla HTML/CSS/JS,
hosted free on GitHub Pages.

**Live demo:** https://munavwar0125-max.github.io/Mini-Calculator-/
**Source code:** https://github.com/munavwar0125-max/Mini-Calculator-

## What it does
- Basic arithmetic: add, subtract, multiply, divide
- Fully responsive grid layout
- Zero dependencies
- Loads instantly, works offline once cached

## What I learned
- Structuring accessible markup with semantic buttons and aria-labels
- Adding SEO essentials (meta tags, JSON-LD structured data, sitemap, robots.txt)
- Deploying and indexing a static site on GitHub Pages from scratch

Feedback welcome — especially on the UI/UX or anything I could simplify
further in the JS logic.
